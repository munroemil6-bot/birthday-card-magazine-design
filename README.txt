TUNDO'S BIRTHDAY CARD — EDITING GUIDE

OPEN THE CARD
Unzip the download, then double-click index.html. It opens in a browser. The included photos work offline. The display fonts are fetched from Google Fonts when connected to the internet.

EDIT THE NAME OR GREETING
Open index.html in a simple text editor such as Notepad. Find the words to change, type your new message, and save. Hope's birthday letter is in the birthday-wish section of index.html.

CHANGE THE PHOTOS OR CAPTIONS
The images folder contains the supplied photos. To replace one, use the same image filename. To edit photo descriptions or gallery captions, open script.js and change the birthdayPhotos list. The featured photo and gallery selection are set using featuredPhotoIndex in script.js.

CHANGE THE COLORS
Open styles.css and change the color values near the top, under :root. This is where the green, warm gold, background, and text colors are grouped.

FILES
index.html — birthday message and page structure
styles.css — colors, fonts, and page appearance
script.js — photo gallery and birthday-wish button
images/ — photos of Tundo and Hope
README.txt — this editing guide
